隐私政策（Privacy Policy）— CiteGuard

适用扩展：CiteGuard — GB/T 7714-2025 文献核验与排版助手 · 最近更新：2026 年 11 月 16 日

1. 核心隐私原则

CiteGuard 坚持“最小权限”和“本地优先”原则。我们不会收集您的浏览器历史记录、Cookie、个人身份信息或任何非您主动触发的内容，也不会向任何第三方广告商、数据经纪人出售或共享用户数据。

2. 权限用途说明

  • sidePanel：用于在 Microsoft Edge 浏览器右侧提供持久化操作面板。
  • storage：仅用于将您的文献池条目、排版偏好（GB/T 7714-2025 / 2015）、隐私同意状态及本地激活状态存储在您本机的浏览器本地存储（chrome.storage.local）中。
  • activeTab 与 scripting：仅在您主动点击「提取当前页面文献」按钮且已勾选隐私授权后，临时读取当前激活标签页公开的学术元标签（如 citation_title、citation_author、citation_doi、DC.* 或页面公开 arXiv ID）。扩展不会在后台自动扫描、监控或抓取任何网页。

3. 外部网络请求说明

本扩展的排版格式化、去重重排以及 Word (.docx) 文件生成全部在您的本地浏览器内离线完成。仅当您主动点击「联网真实性核验」按钮时，扩展才会向以下公开学术开放接口发送文献标题、DOI 或 arXiv ID 查询请求：

  • CrossRef Public REST API (https://api.crossref.org/*)
  • OpenAlex Open API (https://api.openalex.org/*)
  • arXiv Export API (https://export.arxiv.org/*)

扩展不会向自建后台上传您的完整论文全文或个人资料。

4. 免责声明

本扩展提供的文献真伪核验结果基于第三方公开学术数据库返回信息，格式化规则基于 GB/T 7714 公开国家标准。最终投稿或学位论文提交前，请结合所在学校或期刊编辑部最新细则自行复核。

Privacy Policy (English Summary) — CiteGuard

Last Updated: November 16, 2026

CiteGuard is designed with strict data minimization and explicit user consent:

  • No Background Tracking: CiteGuard does not collect browsing history, cookies, personal identifiers, or analytics, and never sells or transfers user data to third parties.
  • Local Storage Only: Your saved bibliography entries, formatting preferences, consent status, and local license state are stored strictly on your device via chrome.storage.local.
  • User-Initiated Page Access: Using activeTab and scripting, metadata extraction (such as citation_* and DC.* academic meta tags) runs only when you explicitly click the "Capture Current Page" button after accepting the in-product consent notice.
  • Public Academic APIs: Only citation titles, DOIs, or arXiv IDs are queried against api.crossref.org, api.openalex.org, and export.arxiv.org when you explicitly trigger online metadata verification.
